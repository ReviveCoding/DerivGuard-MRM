# DerivGuard-MRM

Independent, regime-aware validation and model-risk attribution research for
equity-derivatives pricing models. This repository is research software only:
it is not approved for live trading, production valuation, capital, or
brokerage execution.

The authoritative scope, intended uses, limitations, hypotheses, experiments,
and numerical tolerances are maintained in `governance/`, `experiments/`, and
`configs/`. Scientific phases start as `PENDING`; generated evidence must be
recorded before any phase or acceptance gate can be reported as passed.
