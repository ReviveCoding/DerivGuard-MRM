# Publication Provenance

The GitHub history for DerivGuard-MRM is a sanitized publication history assembled from
the authoritative internal research snapshots. The internal repository remains unchanged
and its immutable evidence manifests and content hashes remain the canonical provenance
for the executed studies.

The public `derivguard-v1.0` tag represents the safe v1.0 publication snapshot. The
public `derivguard-v1.1` tag extends that snapshot with the accepted v1.1 analytics,
reports, figures, source code, tests, frozen registries, safe aggregate results, and
synthetic confirmatory evidence.

The original internal Git commit identifiers are intentionally not reused because the
internal v1 history contained tracked vendor-derived/intermediate SPX option files and
empirical calibration checkpoints. A deletion commit would not have removed those objects
from reachable history.

## Excluded from the public repository

- vendor-derived raw, normalized, quality-flagged, filtered, and processed option data;
- downloaded source-market quote files;
- empirical real-calibration checkpoints;
- raw and contract-level real-data result tables;
- contract-scenario stress rows and other contract-identifying diagnostics;
- local virtual environments, caches, temporary test directories, and build outputs;
- credentials and local execution state.

Reports, publication figures, aggregate derived statistics, synthetic confirmatory
records, freeze/release manifests, hashes, code, configurations, tests, and
reproducibility metadata are retained where redistribution is safe.

The public omission of licensed or contract-level data does not change any accepted
scientific result. It means that full empirical reconstruction requires appropriately
licensed source data and cannot be performed solely from the public repository.
